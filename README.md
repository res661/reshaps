# Reshaps

Фундамент Telegram Mini App: дизайн-система и витрина компонентов. Продуктовых экранов пока нет.

## Запуск

```bash
npm i
npm run dev
```

Откройте http://localhost:5173 — это маршрут `/`, экран «Витрина».

Сборка:

```bash
npm run build
```

Команда проверяет типы клиента и `server/`, затем собирает Vite.

Вне Telegram тема тёмная, как в референсе. Светлый предпросмотр в браузере: http://localhost:5173/?theme=light

## Как открыть в Telegram

1. Создайте бота в [@BotFather](https://t.me/BotFather).
2. Поднимите HTTPS-туннель к локальному серверу (порт `5173`), например cloudflared или ngrok. Telegram открывает Mini App только по HTTPS.
3. В BotFather выполните `/newapp` или задайте Menu Button и укажите URL туннеля.
4. Откройте бота и запустите приложение.

В клиенте Telegram цвета берутся из темы пользователя. При старте вызываются `ready`, `expand` и `setHeaderColor('secondary_bg_color')`. Кнопка «Назад» на вложенном экране — системная BackButton, своей стрелки в интерфейсе нет. Главное действие экрана — MainButton «Готово». В обычном браузере те же действия показаны кнопками страницы, потому что панели Telegram там нет.

## Токен бота

Токен в клиент не попадает и в репозиторий не коммитится. Для будущей серверной проверки `initData` положите его в окружение:

```bash
cp .env.example .env
```

В `.env` одна переменная:

```bash
BOT_TOKEN=
```

Клиент её не читает. Заготовка проверки подписи — `server/validateInitData.ts`. HTTP-эндпоинта пока нет: когда появится бот, он должен читать `BOT_TOKEN` из окружения.
