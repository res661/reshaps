# Дизайн-система

Правила для всех экранов Mini App. Новый экран не вводит свои цвета, радиусы, тени и шрифты. Если правило нужно изменить — сначала меняется этот файл и `src/styles/theme.css`.

Референс: Tribute, тёмная тема, карточки, цветные плитки иконок. Светлая тема включается сама, через переменные Telegram.

## Стек

- React, TypeScript, Vite
- Скрипт `telegram-web-app.js` в `index.html`
- Мобильная колонка 360–430px (`max-width: 430px`)
- Только системный шрифт: `-apple-system, 'SF Pro', Roboto, sans-serif`
- Иконки: `lucide-react`
- Токена бота в клиенте нет. Сервер читает `BOT_TOKEN` из окружения

## Цвета

Токены в `src/styles/theme.css`. Значения темы — переменные Telegram, в скобках запасной тёмный цвет.

| Токен | Значение |
| --- | --- |
| `--bg` | `var(--tg-theme-bg-color, #181818)` |
| `--card` | `var(--tg-theme-secondary-bg-color, #232323)` |
| `--text` | `var(--tg-theme-text-color, #fff)` |
| `--hint` | `var(--tg-theme-hint-color, #8a8a8e)` |
| `--link` | `var(--tg-theme-link-color, #3a8bfd)` |
| `--accent` | `var(--tg-theme-button-color, #3a8bfd)` |
| `--on-accent` | `var(--tg-theme-button-text-color, #fff)` |
| `--danger` | `var(--tg-theme-destructive-text-color, #ff453a)` |

Плитки иконок, фиксированные:

| Токен | Цвет |
| --- | --- |
| blue | `#2f7cf6` |
| red | `#ff3b4e` |
| purple | `#6c5ce7` |
| green | `#2ecc71` |
| orange | `#ff9500` |
| cyan | `#32ade6` |
| pink | `#ff5fa2` |
| slate | `#6b7a99` |

Статусы:

| Токен | Цвет |
| --- | --- |
| `--success` | `#34c759` |
| `--error` | `#ff453a` |
| `--warning` | `#ff9f0a` |

Светлая тема не дублируется отдельной палитрой. В Telegram `--tg-theme-*` уже светлые или тёмные, и `--bg` / `--card` / `--text` / `--hint` / `--link` / `--accent` / `--on-accent` / `--danger` подхватывают их. На `[data-theme="light"]` линия становится `rgba(0, 0, 0, 0.06)`, иначе `rgba(255, 255, 255, 0.06)`.

Вне клиента по умолчанию тёмный запасной вид. `?theme=light` в браузере подставляет светлые значения тех же переменных, чтобы проверить экран без Telegram.

## Глубина

Тени не используем. Глубина только за счёт `--bg` и `--card`. Рамки редкие: `1px` цвета `--line`.

## Отступы

Шкала: 4, 8, 12, 16, 24.

- Боковые поля страницы: 12
- Между блоками: 8–12
- Снизу и сверху к полям добавляется безопасная зона: `env(safe-area-inset-*)` плюс переменные контентной зоны Telegram `--tg-content-safe-area-inset-*`

## Движение

Переходы интерфейса 150–250мс, `ease-out`. В токенах 200мс. Нажатие кнопки, быстрого действия, истории и чипа: `scale(0.97)` и затемнение (`brightness(0.92)`). Ячейка списка только темнеет фоном, без масштаба.

Пульс скелетона длиннее (1.2с): цикл в 200мс не читается как загрузка. `prefers-reduced-motion` отключает анимации.

## Текст

Весь интерфейс на русском. Короткие фразы, без точки в конце. Вопрос можно закончить вопросительным знаком.

## Нажатия

Минимальная зона нажатия 44×44. Если рисунок ниже (чип 34px, дорожка переключателя 31px), кликабельная область всё равно не меньше 44px.

У каждого компонента есть те состояния, которые для него имеют смысл: обычное, нажатое, недоступное, загрузка, ошибка, пусто.

## Компоненты

Каждый компонент — свой файл в `src/components`.

### Card

Фон `--card`, радиус 18, без тени. Обрезка по радиусу.

### Section и List

`Section` — подпись 12px цвета `--hint` над блоком и необязательная сноска. `List` — карточка без внутренних полей, в ней ячейки.

### IconTile и Cell

Плитка 36×36, радиус 10, цветной фон, белая иконка 20px.

Ячейка 52–56px (минимум 54), заголовок 16px. Справа значение цвета `--hint` и шеврон. Вся строка нажимается. Разделитель врезанный: 1px `--line`, начинается после плитки (64px) или с 16px, если плитки нет. `disabled` — непрозрачность 0.4. `loading` — спиннер справа, без затемнения. `error` — заголовок и значение цветом `--danger`.

### QuickActions

Сетка в 3 колонки, промежуток 8, высота около 64. Иконка сверху, подпись 13px. Фон `--card`, радиус 16.

### Button

Варианты: `primary`, `secondary`, `ghost`, `danger`. Высота 48–52 (токен 50), на всю ширину, 16/600. `disabled` — непрозрачность 0.4. `:active` — `scale(0.97)` и затемнение. `loading` — спиннер, кнопка не нажимается и не тускнеет.

- primary: фон `--accent`, текст `--on-accent`
- secondary: фон `--card`, текст `--text`
- ghost: прозрачный фон, текст `--accent`
- danger: фон `--danger`, белый текст

### StoriesRow

Горизонтальный ряд, `scroll-snap-type: x mandatory`, полоса прокрутки скрыта. Плитка 100×110, радиус 18, градиентный фон. Белая жирная подпись 12px внизу слева.

### Chips и Tabs

Высота рисунка 32–36 (34), радиус 999, зона нажатия 44. Активный: фон `--accent`, текст `--on-accent`. Неактивный: фон `--card`. `disabled` — непрозрачность 0.4. Чипы можно выбрать несколько, вкладка одна.

### Input

Высота 48, фон `--card`, радиус 12, без рамки в покое. Плейсхолдер цвета `--hint`. Фокус: кольцо 1.5px `--accent`. Подпись над полем 13px цвета `--hint`. Ошибка: кольцо и текст `--danger`. `disabled` — непрозрачность 0.4.

### Switch, Checkbox, Radio

Вид как в iOS и Telegram. Переключатель справа в строке: дорожка 51×31, бегунок 27px, включено — `--accent`. Чекбокс и радио слева, отметка `--accent`. Строка не ниже 54px, у недоступного непрозрачность 0.4.

### Badge

Пилюля радиуса 999, текст 12. Тона: нейтральный, accent, success, error, warning.

### HeroBalance

Подпись-подсказка, крупное число, справа пилюля-тег.

### BottomSheet

Радиус 20 20 0 0, ручка сверху, тёмный фон-затемнение. Закрытие свайпом вниз или нажатием на фон. Пока шторка закрыта, она не перехватывает нажатия.

### EmptyState

Иконка, заголовок, подсказка, необязательное действие. Фон карточки.

### Skeleton

Пульсирующий блок. Им показывают загрузку списка или карточки.

### Toast

Появляется на 2–3с (2.5с) над безопасной зоной. Тона: обычный, success, error. Success и error дают haptic notification.

## Telegram

Поведение в `src/lib/telegram.ts`.

На старте, если объект WebApp есть:

- `tg.ready()`
- `tg.expand()`
- `tg.setHeaderColor('secondary_bg_color')`
- фон страницы `bg_color`, чтобы не мигала чужая заливка

Дальше:

- Слушать `themeChanged` и заново применять цвета и цвет шапки
- Пользователь берётся из `initDataUnsafe.user`
- Вложенный экран показывает системную BackButton и не рисует свою стрелку. В браузере, где BackButton нет, допустима текстовая кнопка «Назад» и история `history.back()`
- Главное действие экрана — MainButton через хук `useMainButton`. В браузере то же действие — обычная кнопка
- Хаптика: `impact` light на нажатие, `notification` success или error на исход
- Подтверждения через `showConfirm` и `showPopup`, не через `alert`. Вне Telegram те же вызовы открывают карточку в стиле системы
- Нижний отступ: `env(safe-area-inset-bottom)` плюс `--tg-content-safe-area-inset-bottom`. Так же для верха и боков

Проверка `initData` на сервере — `server/validateInitData.ts`. Это заготовка: HMAC по токену из `BOT_TOKEN`, без HTTP. Поле `hash` из строки проверки исключается, `signature` остаётся (отдельная схема Ed25519 для третьих сторон его как раз исключает).

## Что не делать

- Не добавлять тени, градиентный текст, капс и второй шрифт
- Не рисовать свою кнопку «назад» со стрелкой внутри Telegram
- Не класть токен бота в клиент, в репозиторий и в `VITE_`-переменные
- Не собирать продуктовые сценарии, пока для них нет отдельной задачи. Витрина на `/` — только демонстрация компонентов
